# Lưu trữ tài liệu bản 2.7.0

Các tệp ở đây được sao lại trước khi đại tu bản 2.8.0 và không còn được cập nhật.

| Tệp | Ghi chú |
|---|---|
| `README.v2.7.0.md`, `WALKTHROUGH.v2.7.0.md` | Bản mô tả game 2.7.0 (bốn nhiệm vụ, tám bàn giao, ba kết cục good/neutral/oops). |
| `story.v2.7.0.json` | Dữ liệu cốt truyện 2.7.0, giữ để đối chiếu và kiểm migration bản lưu version 3. |
| `AGENTS.v2.7.0.md`, `GDD.v2.7.0.md` | Bản có trong gói 2.7.0 lúc nhận việc. Gói này đã chứa sẵn bộ tài liệu mới (trùng với tệp đính kèm), nên hai tệp này giống bản hiện hành tại thời điểm sao. |
