Bảy ảnh trong thư mục này đã được tải về máy này bằng `python scripts/download_references.py`. Kết quả từng file nằm ở `data/reference_download_report.json` (cả bảy mục `downloaded`). Bản ZIP ban đầu không kèm các ảnh này vì lần tải lúc đóng gói trả HTTP 403; lần chạy sau thì tải được. Không có trang HTML lỗi nào được ghi thành file ảnh.

Nguồn, năm và loại ảnh nằm ở `data/sources.json`. Phối cảnh cải tạo 2024 (`ussh_c_design.jpg`, `ussh_axis_design.jpg`) là ảnh thiết kế, không phải hiện trạng đã xây. App web không tải các ảnh này lúc chạy.
